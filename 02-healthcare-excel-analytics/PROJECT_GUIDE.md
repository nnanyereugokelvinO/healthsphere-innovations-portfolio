# HealthSphere Excel Analytics — Project Guide

## Objective

Demonstrate foundational healthcare data analysis through a reproducible Excel workbook with synthetic patient information.

## Workbook navigation

1. **Patient Data:** Review the underlying fictional records and the fields used for analysis.
2. **HealthSpere Dashboard:** Review summary indicators, status distribution, alerts, and department selection.
3. **Patient Analysis:** Review the department-level analysis and any PivotTable or PivotChart elements.
4. **Department Lists:** Review the dynamic list supporting department filtering.

## Key techniques covered

- Patient counts and status summaries using COUNT, COUNTA, and COUNTIF-style calculations
- Logical checks using IF and AND
- Structured references for expandable Excel Tables
- Department lists using FILTER, UNIQUE, and SORT
- Input validation for patient ages
- Dashboard indicators for patient totals, stability, review requirements, and alerts

## Suggested verification before publication

- Confirm that all patient names and identifiers are fictional.
- Confirm that dashboard counts agree with the Patient Data worksheet.
- Choose a department that currently exists in the dataset; clear any outdated dropdown selection.
- Check that no formula cells show `#REF!`, `#VALUE!`, `#DIV/0!`, or `#NAME?`.
- Refresh any PivotTables if records have changed.
- Review workbook properties, comments, hidden sheets, and external links for information you do not wish to publish.

## Scope

This project illustrates analytical workflow and spreadsheet quality controls. It is not validated for real clinical use.
